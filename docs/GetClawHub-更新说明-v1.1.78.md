# GetClawHub Mac 客户端 · 更新说明（v1.1.78）

一句话：**对话里生成的文档，点一下就能在右侧看；聊天卡死已治本；公式离线也能显示。**

---

## 新功能

### 对话里的文档，点一下直接预览

AI 生成文件后，回复里的文件名现在是**带下划线的链接**，消息底部也有文件小卡片。点一下，右侧就打开这个文档——不用再去 Finder 里翻。

预览面板右上角依次是：

| 按钮 | 作用 |
|---|---|
| `</>` | 看原始文本 / 看排版效果，来回切 |
| 🔍 | 在文件里查找 |
| ▤ | 在项目文件里显示（下方展开文件树，能看到它在哪个目录） |
| 📁 | 在 Finder 中打开 |
| ⧉ | 复制文件内容 |
| ✕ | 关闭 |

关闭的行为按你打开它的方式来：**从对话点开的**，关闭就整个收起、回到全宽聊天；**你自己打开过文件列表的**，关闭则退回文件列表——不会把你正在看的列表一起关掉。

### 跨段选择文本

AI 的回复排版之后，一段一段是独立的，鼠标拖选会在段落交界处断掉。现在把鼠标移到回复上，点工具栏的 **⊹ 图标（跨段选择文本）**，整条回复会变成可连续拖选的纯文本，从开头一路选到列表末尾都没问题，Cmd+C 直接复制。再点一次退出。

> 右键菜单里也有这一项。

## 重要修复

### 聊天界面卡死（治本）

之前偶发的「用着用着整个界面卡死、风扇狂转」，这一版换掉了消息渲染的底层实现（不再让每条消息挂一个系统文本控件参与布局），从根上切断了成因。

### 公式不显示 / 显示很慢

带数学公式的消息以前要**联网去 CDN 下载渲染引擎**才能显示公式——网络不畅时公式干脆出不来，或者先显示一堆源码、过一会儿才变成公式。现在渲染引擎**打包在客户端里**，完全离线可用，且一次渲染到位。文件预览里的公式同样支持。

顺带修掉：以前公式是异步渲染的，气泡高度算错，公式下面会多出或少掉一截空白。

### 文件预览的三个小毛病

- **关闭要点两次**：现在一次点击就关
- **打开时闪两下**：预览会整页渲染两次（一次打开、一次多余的重载），现在只渲染一次
- **先闪一下文件列表**：以前右侧先弹出文件列表、约半秒后才换成文档；现在直接就是文档

### 编辑历史消息时，光标不在输入框里

点「编辑重发」后要先点一下输入框才能打字，且输入几个字后焦点会被抢走。现已修复，打开就能直接改。

## 底层升级

- **内置网关升级到 2026.7.1**，修复上游会话存储导致的对话冻结
- 设置里新增 **「强行修复」**：网关状态异常时一键重置并重启，不用手动折腾
- 客户端不再向任何 CDN 请求脚本（包括一个有过供应链投毒历史的域名），文档渲染全部本地完成
