# GetClawHub Mac 客户端 · 更新说明（v1.1.79）

一句话：**右侧文件面板现在和左侧栏长得一样、用起来也一样。**

---

## 体验改进

### 右侧面板与左侧栏统一

打开右侧的文件面板时，它以前看着像是「聊天区又白了一块」，和左侧栏不是一套东西。这一版对齐了三点：

| | 之前 | 现在 |
|---|---|---|
| 底色 | 和聊天区一样的纯白 | 与左侧栏同一种浅灰（深色模式下同理） |
| 分隔 | 一条明显的竖线 | 靠底色区分，和左侧栏边缘一致 |
| 调宽 | 只有 1 像素宽的线能拖，鼠标也不变形状 | 边界一带都能拖，鼠标移上去变成左右箭头 |

拖动右边界即可调节面板宽度，聊天区会同步重排；面板收起后边界处不再残留调节光标。

## 附：这次踩到的两个坑（供后续维护参考）

留在这里是因为它们都「看起来显然」但实际相反，下次改动很容易重犯：

**1. 左侧栏不是半透明材质，是接近不透明的浅灰。**
一开始尝试用系统的 `.sidebar` 视觉材质去贴近左侧栏，实测最接近的组合渲染出来是 `#DEDFE0`，而左侧栏是 `#F7F7F7`；要补上这个差距需要再叠约 0.76 的白色覆盖 —— 那本质上就是一个实色。所以最终直接绘制取样得到的色值，按浅色/深色两套。

**2. `NSColor(white:)` 是 calibrated gray，在 P3 屏上比同数值的 sRGB 明显偏暗。**
同一个 0.969 用 `NSColor(white:)` 画出来实测约 `#EDEDED`，用 sRGB 分量才是预期的浅灰。涉及取色对齐时一律写 sRGB 分量。

**3. `NSBox` 会自己画边框。**
把分隔条的图层背景色清成透明后，那条线依然在 —— 因为 `.custom` 类型的 `NSBox` 另有一套 `borderWidth`/`borderColor`。两处都要清。

以上三条的契约固化在 `scripts/verify_right_inspector_sidebar_parity.swift`，改动这块前先跑一遍。
