# GetClawHub Mac 客户端 · 更新说明（v1.1.87）

一句话：**侧栏会话可以按活跃、已归档或全部筛选，每行能看到相对时间和消息条数；发出的消息会带上网关身份，断线恢复时能对上历史。**

---

## 这一版改的是什么

上一版把点停止之后的会话枝切稳了。这一版收的是**会话列表本身**：怎么找归档、怎么一眼看出新旧，以及本地气泡和网关记录怎么对上号。交互对齐 Cursor 历史列表，不引入会话 fork。

以前归档只能藏起来，没有单独入口；会话行只有标题，时间和条数挤在悬停提示里；本地 `ChatMessage` 也不记网关 entryId / 发送幂等键，恢复时只能靠时间窗猜。

### 1. 活跃 / 已归档 / 全部

Agent 标题右侧增加筛选菜单，选项是活跃、已归档、全部，会记住你上次选的。

- 默认仍只显示未归档会话。
- 已归档会话右键是「取消归档」，取消后不会抢走当前选中的会话。
- 归档列表为空时有单独文案。

### 2. 会话行显示时间和条数

会话行改成两行：标题 + 灰色消息条数；右侧是相对时间（今天显示钟点，更早显示「昨天」「N 天前」）。

悬停时，时间让位给固定宽度的置顶 / 删除按钮，行高不跳。

### 3. 消息记下网关身份并回填

发送用户消息时，先打上幂等键，再把同一把钥匙交给这次 `chat.send`。助手占位消息共用这把钥匙。

`chat.history` 会带上 entry id 和幂等键。断线或崩溃后恢复时，按这把钥匙把网关记录填回本地气泡，旧会话 JSON 没有这两个字段也能打开。

## 新安装与已有安装

- 新安装、已有安装：升级到 1.1.87 后直接使用，没有额外配置步骤。
- 不要求重装 Node，也不要求再点「安全修复网关」。

---

## 变更边界

只改 GetClawHub 客户端的会话列表展示，以及本地消息与网关历史的身份字段。**不包含会话 fork，也不包含对 OpenClaw 网关核心仓库的修改**，捆绑核心仍是 `2026.7.1-2`。

---

## 升级方式

菜单栏 **GetClawHub → 检查更新**，或重启客户端自动提示。
